# Global Storybooks Chinese — vendored for 朗读

- **What:** the 40 Mandarin (simplified) stories of Global Storybooks (UBC, built from the African Storybook), one Markdown file each.
- **From:** https://github.com/global-asp/sbc-source, folder `zh/`, commit `be28dab38ac55e8eb2185edb6631b11615d02185` (2026-06-08).
- **Pictures:** https://github.com/global-asp/gsn-imagebank, commit `0df409752c86adc92685816e19e6085c4e4496f1`; each passage shows its first page's picture (`<story>/<page + 1>.jpg`, `01` is the cover), converted to WebP in `public/passages/`. A picture carries its story's licence and illustrator credit.
- **Licences (per story):** the Markdown says only `CC-BY` or `CC-BY-NC`; the version comes from Global ASP's master index (https://github.com/global-asp/global-asp/blob/54c9b2378872bfb166e08b13656bf90e392255a2/MASTER.md) and matches each story's page on global-asp.github.io/storybooks-chinese (checked 2026-10-15). CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/) for 20 stories; CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/) for 9: 0027, 0089, 0110, 0201, 0243, 0262, 0296, 0315, 0324 (manifest `licence`); CC BY-NC 3.0 (https://creativecommons.org/licenses/by-nc/3.0/) for 11: 0002, 0003, 0009, 0030, 0067, 0112, 0120, 0129, 0231, 0234, 0271. ZiJi is free and non-commercial; drop the CC BY-NC stories (manifest `include: false`) if that ever changes.
- **Credits:** each story's `License`, `Text`, `Illustration` and `Translation` lines travel with every passage made from it (`credit` in `src/content/storybooks.json`), shown under the passage and in the parent area's Credits.
- **Changes:** light edits only, listed with their reasons in `manifest.json` (Singapore usage 一点儿 → 一点; the traditional 馬 in 0327). A changed story is marked 「有改动」/adapted wherever it is credited.
- **Files:** `zh/*.md` (verbatim at the commit), `manifest.json` (level, include, licence version, names, edits per story), `lib.ts` (parse, edit, chunk, level), `fetch.ts` (re-vendors and fetches pictures), `../import-storybooks.ts` (writes the passages and pictures).
